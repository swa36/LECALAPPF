# Обработка ответа AliExpress при обновлении остатков

## Контекст

Метод `api/v1/product/update-sku-stock` возвращает успешный ответ в виде
словаря с `group_id` и непустым списком `results`. Каждый успешно принятый
элемент содержит `ok: true`. Общий предикат `AliExpress._is_success_response`
этот формат не распознаёт и поэтому создаёт ложное предупреждение об отказе.

## Рассмотренные варианты

1. Добавить распознавание `results[].ok` в общий
   `_is_success_response`. Это компактно, но меняет контракт всех операций
   AliExpress, включая удаление и публикацию карточек.
2. Проверять `results` непосредственно внутри `update_stock`. Изменение
   локализовано, но логика ответа останется смешана с отправкой запроса.
3. Добавить отдельный предикат ответа обновления остатков и вызывать его из
   `update_stock`. Это сохраняет общий контракт остальных операций и позволяет
   отдельно тестировать формат `update-sku-stock`.

Выбран вариант 3 как наиболее узкий и безопасный.

## Контракт

Ответ обновления остатков считается успешным, когда одновременно выполнены
все условия:

- ответ является словарём;
- в нём нет верхнеуровневых ключей `error`, `errors` или `code`;
- `results` является непустым списком;
- каждый элемент `results` является словарём;
- в каждом элементе значение `ok` строго равно `True`.

`group_id`, `task_id` и `external_id` не участвуют в определении успеха:
наблюдаемый успешный ответ содержит нулевой `task_id` и пустой `external_id`.

Пустой список, отсутствующий `results`, `ok: false`, отсутствующий `ok`,
элемент неверного типа или верхнеуровневая ошибка означают отказ. В этом
случае `update_stock` сохраняет существующее поведение: печатает полученный
ответ и возвращает `False`.

## Изменения

- В `AliExpress` появится отдельный статический предикат для ответа
  `update-sku-stock`.
- `update_stock` будет использовать новый предикат вместо общего
  `_is_success_response`.
- Общий предикат и операции удаления/публикации не изменятся.

## Проверка

Регрессионные тесты подтвердят:

- наблюдаемый ответ с несколькими элементами `ok: true` возвращает `True` и
  не печатает предупреждение;
- смешанный ответ, где хотя бы один элемент содержит `ok: false`, возвращает
  `False`;
- пустой `results` возвращает `False`;
- существующие тесты ошибок, таймаутов и других операций AliExpress продолжают
  проходить.
